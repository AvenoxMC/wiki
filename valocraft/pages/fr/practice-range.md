# Stand de tir


Hors partie, une arme obtenue avec `/vc give` tire sur les **mobs et les armor stands**. Elle ne tire jamais sur les joueurs.

Chaque tir touché affiche :

- La **zone** touchée
- Les **dégâts** infligés
- La **distance**

C'est le moyen le plus simple de régler `weapons.yml` avant d'ouvrir une partie.

## Utilisation

```
/vc give <arme> [joueur]
```

Tirer sur des mobs ou des armor stands, ajuster `weapons.yml`, puis `/vc reload`.

## Désactivation

Régler `weapons.practice-mode` dans `config.yml` pour le désactiver. Voir [Configuration](page:configuration).

Voir aussi : [Armes](page:weapons).
