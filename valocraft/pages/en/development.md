# Development


## Building from source

Requirements: **Java 21** and **Maven**.

```bash
mvn package
```

The jar is produced at `target/Valocraft-2.2.jar`.

## Where to change things

| What | Where |
|---|---|
| Ability damage, durations, prices | `AbilityType.java` and `Kits.java` |
| Weapon stats | `weapons.yml` (no rebuild needed) |
| General settings | `config.yml` (no rebuild needed) |
| Weapon models | `resourcepack/valocraft-models/` |
| Model generator | `resourcepack/ModelGenerator.java` |
| Model preview | `resourcepack/apercu-armes.png` |

## Weapon models

The custom Valocraft models (Shorty, Frenzy, Stinger, Bucky, Judge, Bulldog, Guardian, Phantom, Marshal, Outlaw, Odin) are generated by `resourcepack/ModelGenerator.java` into `resourcepack/valocraft-models/`. They use the `item_model` component (`valocraft:<weapon>`).

To retouch a model, open it in **Blockbench** (Java Block/Item format).

## Resource pack

The HrdaValorant pack is embedded in the jar and extracted to `plugins/Valocraft/resourcepack.zip` at first start. See [Resource Pack](page:resource-pack).

## Contributing

- Open an **issue** for bugs and balance feedback. Abilities have not yet been balanced in real matches, so reports with context (agent, ability, situation) are very useful.
- Pull requests are welcome.
