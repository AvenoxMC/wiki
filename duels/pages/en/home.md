# Avenox Duels

**Avenox Duels** is a duelling plugin for **Spigot 1.8.8**. It supports 1v1 queues, direct challenges, parties, configurable kits, and arenas copied on demand for each match.

> Every match runs in a fresh copy of its arena. The copy is removed when the match ends, so damage to the map never carries over to the next match.

## Quick start

1. Install the plugin as described in [Installation](page:installation).
2. Set the lobby with `/duels setlobby`.
3. Create and save an arena; see [Arenas](page:arenas).
4. Join a queue with `/queue`, or challenge someone with `/duel`.

## Highlights

- **Disposable arena instances**: each match uses a temporary copy of its template world.
- **Several ways to play**: queue, direct challenge, FFA parties, team parties and party-versus-party.
- **Map tools**: create arenas in-game or paste supported WorldEdit schematics.
- **Configurable kits** and the non-combat **Guess!** mastermind mode.

## Compatibility

The plugin targets **Spigot 1.8.8**. The README does not specify support for other server versions; test compatibility before using another version.
