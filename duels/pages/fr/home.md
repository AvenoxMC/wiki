# Avenox Duels

**Avenox Duels** est un plugin de duels pour **Spigot 1.8.8**. Il propose des files 1v1, des défis directs, des parties entre amis, des kits configurables et des arènes copiées à la demande pour chaque match.

> Chaque match se joue sur une copie neuve de l'arène. Cette copie est supprimée à la fin : les dégâts faits à la map ne persistent pas pour le match suivant.

## Démarrage rapide

1. Installer le plugin comme décrit dans [Installation](page:installation).
2. Définir le lobby avec `/duels setlobby`.
3. Créer et sauvegarder une arène ; voir [Arènes](page:arenas).
4. Rejoindre une file avec `/queue` ou défier un joueur avec `/duel`.

## Points forts

- **Instances d'arène jetables** : chaque match utilise une copie temporaire du monde modèle.
- **Plusieurs modes de jeu** : file, défi direct, parties FFA, en équipes ou contre une autre party.
- **Outils de map** : création en jeu ou collage de schématiques WorldEdit compatibles.
- **Kits configurables** et mode mastermind sans combat « Devine ! ».

## Compatibilité

Le plugin cible **Spigot 1.8.8**. Le README ne précise pas la compatibilité avec d'autres versions ; testez avant d'utiliser une autre version.
